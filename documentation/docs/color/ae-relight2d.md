# aeRelight2D AE

**Author:** Aitor Echeveste - [https://aitorecheveste.com](https://aitorecheveste.com)

- [https://aitorecheveste.com/aerelight-overview/](https://aitorecheveste.com/aerelight-overview/)
- [https://github.com/aitorecheveste/aeTools](https://github.com/aitorecheveste/aeTools)

Make relights of footage without needing any render passes. Especially useful when trying to illuminate smoke or atmospheric elements. Set the emboss and light direction for a fake relight effect from 2D elements.
