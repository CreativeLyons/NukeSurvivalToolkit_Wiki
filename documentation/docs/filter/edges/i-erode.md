# iErode PP

**Author:** Phil Prates - [https://philprates.com](https://philprates.com)

- [https://www.nukepedia.com/tools/gizmos/filter/pp_erode/](https://www.nukepedia.com/tools/gizmos/filter/pp_erode/)

An iterative erode that allows for masking without doubling edges. A standard filter erode with a mask input that iterates the erode amount along the mask alpha, preventing edge doubling while masking.
